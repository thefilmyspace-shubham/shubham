# TFS Editing Memory

Living memory for The Filmy Space editing decisions. Update it after every reference studied, every review and every piece of feedback.
Rules: evidence only (no invented trends or performance numbers); one client's preference is never applied to every client; a pattern becomes a TFS standard only after a successful TFS test.

Status labels: LOW USE · HEALTHY · RISING · HIGH USE · OVERUSED · FATIGUED · CLIENT-SPECIFIC SIGNATURE · TESTING
Trend pipeline: DISCOVERED → VERIFIED → RECOMMENDED → APPROVED FOR TEST → TESTING → SUCCESSFUL / FAILED → REPEATABLE / REJECTED

---

## 1. Shubham Taste Memory

Everything below comes from Shubham's own messages in the TFS promo / brand-reel sessions (Oct 2026).

**Always / approved**
- Shubham approves the **script, storyboard or VO before any production starts**.
- Export **4K 60 fps**.
- **The TFS logo must never be changed** (use the original file only).
- Agency promo ending: **no outro, just the logo**.
- Royalty-free music + **sound effects are expected**. ElevenLabs is used for VO/SFX.
- **Client logos and client reels may be used** in TFS promos.
- "Clean and minimal" when the reference is clean and minimal: follow the reference's format, font feel, animation and timing closely.
- English only when asked (Foretell-style reel).
- Claim allowed: **20+ brands**.

**Never / rejected**
- **No price on screen** in TFS promos.
- No "local legacy" positioning.
- **Never repeat the same clip or moment** inside one edit ("ek hi chiz repeat mai mat use kro"). Pull from many different client reels (Funhoods was missed once and called out).
- A generic animation style that doesn't match the reference ("refrence jese animation nhi hai").
- A montage tacked on at the end ("outro edit") was removed from the vertical reel.

**Open signals (investigate, don't just store the word)**
- Brand reel v1: "video is not engaging, edit wesa nhi hai". The underlying causes found were reused clips, small text layouts, timing off the music, and flat 2D graphics with no depth.
- Brand reel v2: "not getting the feel". Causes found: text arriving late versus the VO, layouts too small, no texture/depth, no 3D assets. These were fixed in v3, which is **awaiting feedback**.
